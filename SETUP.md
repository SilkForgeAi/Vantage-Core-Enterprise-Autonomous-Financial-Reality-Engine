# Setup Guide

Prerequisites

- Python 3.10+
- Redis server
- API keys for at least one LLM provider (OpenAI or Anthropic)
- Exchange API keys (Binance, Bybit, etc.)
- Telegram Bot Token (optional, for Telegram interface)

Step 1: Install Dependencies

```bash
pip install -r requirements.txt
```

Step 2: Set Up Environment

```bash
# Generate .env file
python setup.py

# Edit .env with your API keys
nano .env  # or use your preferred editor
```

Required environment variables:
- `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` (at least one)
- `ENCRYPTION_KEY` (auto-generated by setup.py)
- Exchange API keys if you want to connect exchanges
- `TELEGRAM_BOT_TOKEN` if using Telegram interface

Step 3: Start Redis

```bash
# On macOS with Homebrew
brew services start redis

# On Linux
sudo systemctl start redis

# Or run directly
redis-server
```

Step 4: Initialize ChromaDB

ChromaDB will auto-create the directory on first run. Make sure the path in `.env` is writable:

```bash
mkdir -p chroma_db
```

Step 5: Run the Backend

```bash
# Start FastAPI backend
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at `http://localhost:8000`

Step 6: (Optional) Run Telegram Bot

In a separate terminal:

```bash
python backend/telegram_bot.py
```

Step 7: Add Exchanges for Users

Via API

```bash
# First, encrypt your API keys (or use the Python script)
python scripts/add_user_exchange.py <user_id> binance <api_key> <api_secret>
```

Via Python Script

```python
from security.encryption import KeyEncryption
from config.settings import settings

encryption = KeyEncryption(settings.encryption_key)
encrypted_key = encryption.encrypt("your_api_key")
encrypted_secret = encryption.encrypt("your_api_secret")

# Then POST to /api/user/add_exchange with encrypted values
```

Step 8: Test the System

Test Intent Consistency

```bash
pytest tests/test_intent_consistency.py -v
```

Test via API

```bash
# Send a message
curl -X POST "http://localhost:8000/api/agent/message" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "test_user_1",
    "message": "check my USDT balance"
  }'
```

Test via Telegram

1. Start the Telegram bot
2. Send `/start` to your bot
3. Send natural language commands like:
   - "buy 0.1 BTC"
   - "check my USDT balance"
   - "what positions do I have?"

Important Notes

Safety

- By default, `ENABLE_LIVE_TRADING=false` - This prevents real trades
- Set `ENABLE_LIVE_TRADING=true` only when you're ready for real money
- Test thoroughly on sandbox/testnet first

Multi-User Support

- Each user has isolated state, memory, and exchange connections
- User IDs can be any string (Telegram user ID, UUID, etc.)
- State is persisted in Redis and ChromaDB

Latency

- Target: <10 seconds end-to-end (message → fill confirmation)
- Latency is logged in audit logs
- Use `MAX_EXECUTION_TIME_SECONDS` in `.env` to set limits

Exchange Configuration

- Supported exchanges: Any CCXT-supported exchange
- Tested with: Binance, Bybit
- Add more by connecting additional exchange instances

Troubleshooting

Redis Connection Error

```bash
# Check if Redis is running
redis-cli ping
# Should return: PONG
```

ChromaDB Errors

```bash
# Delete and recreate ChromaDB directory
rm -rf chroma_db
mkdir chroma_db
```

API Key Encryption

If you need to regenerate encryption key:

```bash
python scripts/generate_encryption_key.py
# Update ENCRYPTION_KEY in .env
# Note: This will invalidate all existing encrypted keys
```

LLM API Errors

- Check your API key is correct
- Ensure you have credits/quota available
- Try a different model in `DEFAULT_MODEL`

Production Deployment

For production:

1. Use environment variables (not .env file)
2. Set up proper Redis persistence
3. Use a production WSGI server (e.g., Gunicorn)
4. Set up monitoring and alerting
5. Use proper secrets management (AWS Secrets Manager, HashiCorp Vault, etc.)
6. Enable HTTPS/TLS
7. Set up rate limiting
8. Monitor latency and optimize
